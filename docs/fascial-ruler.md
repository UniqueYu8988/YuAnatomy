# 间隙示意与测距维护

## 范围与方法

`app/fascial-spaces.ts` 是解剖关系知识库。现有8个间隙只表示左侧局部关系，不模拟患者脓肿、完整筋膜或Ludwig咽峡炎的双侧病变。查看顺序不是感染必经顺序。保留38的文字情景，但当前28颗牙没有38，不伪造三维智齿病灶。

`public/fascial` 是离线几何包。`scripts/build-fascial.py` 用现有187个骨、肌、牙和相关消化组织网格构建0.8mm占据体素，另加一格生成保护余量；咬肌/翼下颌间隙沿下颌支与相邻肌肉之间构建局部间隔；舌下/下颌下区域受当前左下颌舌骨肌上下面约束。其他区域是局部范围与现有组织相减，缺失筋膜、皮肤或小肌肉的边界未重建。

占据体素使用源网格体素化并填充，开口网格及跨版本配准均带来不确定性。0.8mm是计算网格间距，不是标本扫描分辨率或医学精度。不得宣称这些体积为真实潜在间隙全部范围。

等值面经有限平滑（位移上限0.16mm、约束在允许区域内），不修改任何原始牙体、髓腔、骨骼和肌肉。重新构建需 `scripts/pulp-requirements.txt` 中依赖，放入 `work/pulp-runtime` 后运行 `python scripts/build-fascial.py`。中间缓存 `work/fascial-voxels` 的原始几何SHA不匹配时须重新生成。

## 验证与许可

`npm run validate` 包含 `scripts/validate-fascial-ruler.mjs`：核对源几何哈希、包体及gzip、三角形索引、闭合边、58.8万余个表面采样点对组织占据体素的避让、间隙/边界ID与路径关联。测试对照实际占据体素，额外外扩保护层不是组织本身。允许Float32坐标恰位于体素边界的舍入误差；这不是逐三角面精确碰撞认证。测试失败应修复网格，不得删掉测试。

保留 `public/fascial/ATTRIBUTION.md`；基于BodyParts3D 4.0（CC BY4）和3.0咀嚼肌（CC BY-SA2.1JP）的独立改编数据。不要把间隙二进制标成MIT代码。

## 测距

`app/measurement.ts` 计算以米存储的模型点的毫米直线距离及三个解剖方向绝对跨度；不是沿面长度、牙根工作长度或患者测量。拾取与渲染使用一致的剖切半空间，遍历相交点直到遇到保留的表面；不把被裁去的表面或人工截面填充当作原始表面。

`SceneState.rulerReset` 是显式复位信号，必须同时清空React结果和Three.js锚点、预览线、标签。禁止只setRulerMeasurement(null)。完成后点击第三点不自动覆盖测量。模型作用域/隐藏/剖切变化清空已过期结果；旋转保留结果。测量/间隙模式归位并禁用拆解，防止把展开位移量当作解剖距离。
