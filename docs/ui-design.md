# 工作台界面规范（2026-09-08）

视觉升级集中在 `app/workspace-polish.css`，由 `web/main.tsx` 在基础样式后加载。医学知识与几何数据不在本轮修改范围内。

## 设计约定

- 桌面采用浅灰绿底色、三个独立圆角区域：导航、模型、知识。绿色实底用于当前主题及启用工具，正文保持深色。
- 左栏 248px，右栏 348px；1024px 等中等屏幕适当收窄。900px 以下使用导航抽屉，680px 以下改为上下布局。
- 字体使用 Segoe UI 与系统中文无衬线字体，不依赖网络字体。正文 16px、行高 1.85；界面控件 13–14px；详情标题 25px。
- 模型上方保留当前主题标题。工具栏采用轻底色；牙位盘只展示牙位数字，完整牙名保留在 title 与 aria-label 中。
- 手机默认收起牙位盘，用户仍可展开。两行工具栏可横向滚动；页面可纵向滚动阅读完整知识区。
- 知识折叠区用分隔线减少卡片嵌套；数值使用等宽数字；六界采用“方向 / 内容”逐行排版。
- 删除重复的操作解释，保留医学示意限制、原始署名与来源。
- 交互新增的 matchMedia 监听必须卸载清理；遵守 reduced-motion，保留键盘焦点。

## 验证

已查看 1440×1000 桌面（牙列、选牙、根管分型、间隙）、1024×768 和390×844 手机布局。1024px 文档宽度与视口一致；手机模型不再被默认展开牙位盘遮蔽。浏览器无运行时错误。check / validate / build 通过；现有大型 Three.js 主包仍有构建体积提示。

后续改动应在这份视觉样式中按模块调整，避免继续叠加彼此冲突的全局样式文件。截图保存在 `outputs/ui-*.png`。

## 恒牙列拆解

`app/explosion-layout.ts` 对纯牙体集合采用上下两行牙弓展开：上行17→11、21→27；下行47→41、31→37。按面对患者的方向显示，患者右侧在画面左侧。恒牙列默认正面视角，拆解时不绕到侧面。

`app/dental-unfold.ts` 从源网格主轴和相邻牙的牙弓切线估计显示坐标系，以刚体旋转将长轴竖直、估计的唇颊方向朝向观察者。这是自动几何取向，不是经逐牙人工标注的临床轴，也不是曲面断层影像生成；不可描述为X光、压平或拉伸牙体。

列宽使用旋转后的实际牙体宽度，上下同列对齐，左右相邻留2mm显示间距、行高留8mm余量（仅为布局参数）。混合骨骼等结构继续使用通用布局。GPU顶点与法线、剖切模板、拾取网格、髓腔及悬停投影必须使用同一旋转和平移。源网格不改写。开始拆解自动收起牙位盘。

验证脚本覆盖两行顺序、源顶点变换后全部落在显示单元内、单元不重叠及刚体距离不变。浏览器验证右上第二磨牙17点击及髓腔同步。效果截图：`outputs/dental-unfold-two-rows.png`。
