# 冠方环纹与保边去噪对照（2026-09-11）

## 本轮结论

**环纹减轻，但没有恢复可信的完整髓室；本轮处理不替换已有候选。**

在 Specimen045 的 1250–1550 连续 301 层上，比较原图、Gaussian σ0.6、双边滤波、环纹校正加 Gaussian、环纹校正加双边滤波，共 5 种处理 × 3 个固定阈值。阈值 30 时，与起始层相连的候选最冠方位置仍为 1383–1388。这里的层号小表示更冠方；这不是解剖终点或临床工作长度。

这一结果不支持“只要去掉环状伪影，就能恢复完整髓室”的假设，也不证明标本不存在冠方髓腔。当前没有独立专家参考轮廓，不能计算真实牙体的准确率、漏分率，不能诊断钙化。

## 方法与原图保护

- 全部源 PNG 只读。实验 ROI 为 Y550:1000、X550:1100，原始灰度保持 0–255 数值单位。
- 用 1035、1100、1200 三层估计环纹中心，避开评价层段。初始搜索与扩展 31×31 整像素搜索均给出 Y811、X817；另一局部峰附近 Y818、X816 及图像中点 Y816、X816 纳入敏感性比较。该估计不是扫描仪几何标定。
- 自定义探索性校正：极坐标径向高通（σ9 像素）的角向中位数，扣除幅度限制为 ±6 灰度，中心和半径 170 像素边界逐渐衰减。它不是复现论文的现成模型，也没有声称是最优去环方法。
- 双边滤波：灰度 σ5、空间 σ1 像素、7×7 窗口。没有形态学膨胀、补层、生成式修复或强制连管。
- 追踪初始锚点来自上一轮 1550 层自动候选，不是独立人工标注。分别记录能重新捕获的小块，以及严格与起始层相连的范围；断开以后不会把新小块算作连续延伸。

环状伪影可通过极坐标变换转成条纹后处理，方法概念见 [Algotom 官方说明](https://algotom.readthedocs.io/en/latest/toc/section4/section4_3.html)。双边滤波参数含义及保边去噪参考 [scikit-image 官方文档](https://scikit-image.org/docs/stable/api/skimage.restoration.html#skimage.restoration.denoise_bilateral)。这些资料不验证本次自定义参数对牙髓重建的准确性。

## 真实切片结果

与 1550 起始层保持六邻域连续的最冠方候选层：

| 处理 | 阈值 25 | 阈值 30 | 阈值 35 |
| --- | ---: | ---: | ---: |
| 原图 | 1384 | 1383 | 1383 |
| Gaussian σ0.6 | 1385 | 1383 | 1383 |
| 双边滤波 | 1385 | 1384 | 1383 |
| 环纹校正 + Gaussian | 1531 | 1388 | 1383 |
| 环纹校正 + 双边滤波 | 1385 | 1384 | 1383 |

环纹残差代理指标的跨层中位数从原图 1.492 降至“环纹 + 双边”的 0.443，约下降 70%。**这是处理直接作用的指标，不是独立质量指标，更不是解剖准确率提高 70%。** 目视对照显示纹理变干净，但较冠方仍没有可靠髓室边界。

阈值 35 的原图/轻度平滑追踪可拾到 1250 层的暗点，但相邻层多次不重叠。这些远端暗点不能被算成连续髓腔。

中心敏感性也暴露风险：在“环纹 + Gaussian、阈值 25”中，仅改变中心选择，连续终点便从 1531 变为 1385；阈值 30 为 1388 或 1384，阈值 35 均为 1383。不能依据某一个中心参数得到更长结果就采纳。

## 已知真值的合成压力测试

测试不模拟牙本质微结构，只检验算法副作用。背景灰度 45，目标分别为 20 和较弱对比的 28，固定阈值 30；六种几何条件、加环/无环、五种处理，共 120 条结果。Dice 是二维合成目标重叠率，不是本标本精度。

“加环 + 噪声”的弱对比测试：

| 已知合成结构 | 原图 Dice | 环纹 + 双边 Dice |
| --- | ---: | ---: |
| 偏心圆，半径 2 像素 | 0.917 | 0.818 |
| 偏心圆，半径 4 像素 | 0.833 | 0.935 |
| 偏心圆，半径 8 像素 | 0.813 | 0.990 |
| 位于中心的圆，半径 8 像素 | 0.673 | 0.479 |
| 真实暗环，径向半宽 2 像素 | 0.951 | 0.080 |

即使整体灰度误差下降，最细、居中或真实环形结构也可能被损伤。因此不能把保边滤波理解为“所有微小管腔都被保留”。空白对照未产生低于阈值的假管腔，但这也不保证真实牙体没有误分。

## 下一步优先级

不继续围绕同一低证据区域放宽阈值“雕出”髓室。优先筛选**同牙类、冠方髓腔在连续原图中更清晰的第二标本**作对照，并保留本标本作为困难影像样本。只有原图有可复核的边界、分割方法对细小结构副作用可控，才进入新的完整髓室建模。公开重建 PNG 的增强不能恢复它未记录的原始投影信息。
