## 当前结论

已新增 509 张经 CRC 核验的冠方切片，复用两张已核验的稀疏样本，并生成带观测范围标记的同标本参考外形与根部候选配对数据。**完整冠根衔接仍未完成**：下载服务返回 HTTP 403，本轮停止网络请求，没有绕过访问限制。缺失影像不插值、不补牙、不补管。

已有原图提示，不能通过简单提高灰度阈值“恢复”髓室：它会把大片牙本质样区域纳入暗区。该标本能否作为正常完整牙的标准模型仍未确定。

## 2. 冠部阈值压力测试

在原图上用同样的逐层 Gaussian σ=0.6 比较阈值，并排除通到裁剪边缘的低灰度连通域。这里比较的是“最大封闭暗区”，不是已由专家标注的髓室。

| 源层 | 阈值 30 的最大暗区面积 | 阈值 50 的最大暗区面积 |
|---|---:|---:|
| 1035 | 73 像素 | 109583 像素 |
| 1358 | 24 像素 | 97119 像素 |

逐图检查可见，高阈值将大片牙本质样区域纳入候选；不能用它扩大髓室或填补追踪中断。两行比较中的最大暗区可能不是同一结构，面积变化不是同一髓室的测量或生长。

`output/crown-extension/threshold-overgrowth.png`、`threshold-stress.json` 保存对照。`sparse-crown-window-comparison.png` 保存不同显示窗宽的原图，不改变像素或生成结构。

冠部 source 712 有明显分离样暗隙，部分切片有环状伪影。原因尚未确认；不能据此诊断裂牙或髓腔钙化，也不能直接命名为正常髓室。源重建日志已经设置 Ring Artifact Correction=14、Smoothing=0；有设置并不意味着伪影已消除。

## 3. 同一标本外形与内部候选的配对

输出在 `output/paired-specimen-partial/`，文件名和说明明确标记为不完整试验。

- `raw-overview-20um.nrrd`：已有原始切片每两个体素取一个的灰度参考。约 20 μm 是显示采样间距，不是原始扫描准确度。
- `tissue-overview-20um.nrrd`：阈值筛选的组织候选，保留足够大的多个同层分量；不宣称已区分釉质、牙本质、牙骨质。
- `envelope-overview-20um.nrrd`：逐层填充封闭孔洞的外形参考。外通缺口不靠形态学闭运算补齐；仍需注意逐层填孔不等于真实组织边界标注。
- `observed-overview-20um.nrrd`：1 表示这一参考层有源图像，0 表示缺失。缺失处的灰度零值不是背景或解剖空腔。
- `cavity-candidate-10um.nrrd`、`cavity-candidate-native.ply`：将此前原始网格上的根部候选放进同一源坐标框架。冠部未估计区域的零值不证明没有髓室。
- `tooth-envelope-overview-40um.ply`：仅用于外形配对查看的约 40 μm 采样曲面；未冒称为原始精度的牙体网格。
- `paired-source-projections.png`：源轴方向的投影图。灰色为参考外形，绿色为已有内部候选，粉色为缺失参考层。投影重叠不能证明三维包含关系。

第一版参考外形裁剪在 source 839 被边界检查拒绝。原图中组织候选最小 X 为 371，超出最初 X≥400 的裁剪。已将 X 范围扩展至 250–1200，重新生成；没有删除或放宽边界检查。源原点为 section/Y/X = 389/300/250。

由于缺层，外形曲面会出现人为截断面。它们不是解剖断面，更不能解释为病变。源坐标不是患者解剖坐标，不据此指定颊舌侧或 FDI 牙位。

外形参考的二值采样存在接触歧义：最初 Lewiner 等值面在 level=0.5 有 75 条多于两面的边，未通过网格检查。改用同一标签、同一等值的 Lorensen 三角化后，封闭性及绕向检查通过；原体素标签没有改变。这只解决参考曲面的表达问题，不证明这些接触的解剖拓扑。失败计数与方法保留在 `surface-audit.json`，原 NRRD 标签优先于预览曲面。

## 4. 验证与复现

`validate_paired_specimen.py --partial` 对 NRRD 解压数据与缓存逐字节比对，核对物理原点与采样间距，并将已有的代表层与原 PNG 的对应取样逐像素比较。曲面另查面数、封闭性和绕向。结果保存 `output/paired-specimen-partial/validation.json`。这些属于文件与坐标验证，不是医学真值验证。

本轮五个 NRRD 的回读检查、11 张源图像的坐标取样检查、两个曲面的封闭性与绕向检查全部通过。已有根部候选在约 20 μm 参考采样点上未落到外形标签之外；由于两者使用相关分割方法，这不能作为独立的牙本质厚度或医学包含性证明。冠部外形边缘仍有伪影影响，不能以三角面数量或网格封闭性替代审校。

主项目 `npm run check`、`npm run validate`、`npm run build` 本轮通过，既有大包体提示仍在。正式软件内容未改动。

以下命令都在项目根目录运行，仅处理本地缓存，不请求网络：

```powershell
python experiments/microct-pilot/extract_cached_crown.py
python experiments/microct-pilot/audit_crown_thresholds.py
python experiments/microct-pilot/build_paired_specimen.py --export-partial
python experiments/microct-pilot/validate_paired_specimen.py --partial
```

完整数据取得后，才运行 `extend_crown_candidate.py`，然后不带 `--export-partial` 构建。完整模式要求所有 2585 条源记录，不允许以 partial 清单冒充完整数据。

下载器已增加请求失败记录与 401/403 后取消排队请求的处理；不能循环重试拒绝访问来凑齐数据。本轮等待完整清单的任务已停止，未留下无限等待的后台追踪任务。

## 5. 后续决策

先补齐缺失的冠根衔接数据，再评估连续追踪与局部灰度证据是否足以恢复髓室。如果仍不能分辨，应更换有更可靠对比度或参考标注的标本，而不是用教材形状替代看不清的原始结构。这一标本的可疑区域可以作为研究材料，但目前不应充当正常髓室默认模型。
