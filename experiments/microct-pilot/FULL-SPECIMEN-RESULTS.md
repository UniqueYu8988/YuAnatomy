## 影像判读与限制

已目视检查 `output/crown-extension/crown-source-comparison.png` 和 `output/paired-specimen/paired-source-projections.png`。冠方切片中有明显环状纹理；712 层有分离样间隙。仅凭这些影像不能诊断裂纹、钙化或确定标本属于正常牙。

既有阈值压力实验显示，把阈值提高到 50 会把大片牙体区域纳入低灰度分割。本轮不采用这种方式扩大髓室。阈值 35 追踪更远也伴随明显不连续，暂不能作为解剖改善。

外包络概览在冠部仍可见横向毛刺，反映阈值与影像伪影影响；不是完成精修的牙体。其二维孔洞填充不是釉质/牙本质组织分割。候选表面封闭是提面结果，不代表真实根尖孔已被恢复。投影图不能用于判断根管数、分型或全体素包容性。

## 交付与复现

输出目录 `output/paired-specimen/`：

- `raw-overview-20um.nrrd`：每两体素抽样的原始灰度概览。
- `tissue-overview-20um.nrrd`、`envelope-overview-20um.nrrd`：组织阈值与填孔参考。
- `observed-overview-20um.nrrd`：观测覆盖，本轮全覆盖。
- `cavity-candidate-10um.nrrd`：全范围原始网格候选标签，零值不等于确认不存在髓腔。
- 两个 PLY：共用源坐标，禁止独立缩放后硬塞进现有牙体。
- `report.json`、`validation.json`：生成与独立读取核验记录。

复现顺序：

```powershell
python experiments/microct-pilot/extend_crown_candidate.py
python experiments/microct-pilot/audit_crown_continuity.py
python experiments/microct-pilot/build_paired_specimen.py
python experiments/microct-pilot/validate_paired_specimen.py
```

## 下一研究门槛

当前瓶颈转为冠方低对比与环状伪影，而非缺失下载。下一步宜先建立局部原图人工参考轮廓，比较保边去噪/环伪影抑制前后的漏分、误分和连通性；不得仅以更平滑、更大或更长作为成功标准。如果原始重建仍无足够边界证据，应换取髓室清晰的同牙类标本作为对照，不能凭形态预期填补本标本。真实标本重建与统计形态模拟必须分别标注。
