# 第四轮：腔内与外部介质分界

2026-09-08。Tomo1B，沿用第三轮100×66×76局部体数据。来源、衍生数据许可见ATTRIBUTION.md。未替换正式模型。

## 实验与结果

运行 `python experiments/microct-pilot/separate_outlet.py`。使用两个竞争种子标签：旧主腔隙内腐蚀一层的区域为腔内种子，距旧牙体包络至少3或8体素的低密度区域为外部种子。固定σ0.6、阈值75，比较灰度梯度分水岭与负距离场分水岭；腔内种子的最末源Z取940/950/960，交叉共12组。

种子全部是算法派生，未经专家标注。旧包络参与种子设置，存在先验偏差。下面位置为1起的源TIFF序号。

| 方法 | 人工分界所在层范围 | 观察 |
|---|---|---|
| 灰度梯度、外种子距包络3体素 | 968–972 | 本次不随三种内种子末层变化 |
| 灰度梯度、外种子距包络8体素 | 970–975 | 外种子位置改变使分界后移 |
| 负距离场、内种子末Z940 | 948–951 | 提前截断可见根管 |
| 负距离场、内种子末Z950 | 953–956 | 分界随内种子后移 |
| 负距离场、内种子末Z960 | 964–969 | 仍由种子与几何假设影响 |

12组并集8780体素，一致腔内部分6156体素，分歧2624体素，占并集约29.9%。这些只描述根尖ROI，不是整颗牙。分歧不是概率或误差置信区间。

**判定：本轮未得到可认定为真实出口边界的最终分割。** 负距离场方案在此次测试中可能提前截断原图清楚可见的管腔，不适合直接采纳。灰度梯度方案可作为进一步审查候选，但外部种子改变也会移动切界，尚未验证。

## 为什么这不是“修补后已完成”

在开放低密度空间里，内部腔隙与外部介质没有一堵可由算法直接检测的隔墙。竞争生长必然产生分界，但这条人工分界并不自动对应根尖孔、狭窄或组织学边界。界面必须显式保存，不能悄悄作为封口导出。

本轮label 0含未分配和高灰度区域，不能称为已验证矿化组织标签；1/2分别为算法腔内/外部候选。另保存灰度65–85不确定带，和12组之间的分歧掩膜。尚未形成专家确认的三组织类别。
