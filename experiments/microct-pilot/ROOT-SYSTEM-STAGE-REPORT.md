# 标本 045：连续根部重建与候选出口复核

日期：2026-09-09。独立离线研究阶段；没有替换正式软件模型。

本轮将此前 324 层的局部分叉研究，推进到了 **1293 层连续影像的根部候选腔隙重建、后段共同腔隙敏感性分析和两处候选末端复核**。结果支持继续使用真实 micro-CT 逐层提取细节，而不是用圆柱或预设曲线拟合。结果尚不足以宣布获得正常牙的完整、医学审校通过的根管系统。

## 1. 数据与来源

- 数据对应 Haberthür 等的永久下颌尖牙研究。**045 是标本编号，不是 FDI 45**；不得据此指定右下第二前磨牙。
- [原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC8040229/)、[作者分析仓库](https://github.com/habi/zmk-tooth-cohort)、[标本下载入口](https://osf.io/fqm4x/download)、[OSF 项目元数据](https://api.osf.io/v2/nodes/rt3da/)。元数据副本位于 `source/cohort-screening/`。
- 本轮新增 source 2005–2973 的 **969 张** PNG；加上已有 1681–2004 的 324 张，形成 1681–2973 的 1293 张连续影像。没有用插值补层。
- 逐文件 ZIP CRC、解压长度和 SHA-256 已核验。仅获取了 ZIP 的部分区间，**未验证整个 ZIP 的发布方哈希**。
- 源 PNG 为 1632×1632、uint8；扫描投影的 16 bit 不能当作导出 PNG 的位深。重建日志给出体素间距 9.99999 μm，不能等同于实际解剖测量准确度。
- OSF 内容公开，但已取得的项目元数据没有明确数据再分发许可。仅保留本地研究产物，不能沿用另一标本 Tomo1B 的 CC BY 4.0。见 [COHORT-ATTRIBUTION.md](COHORT-ATTRIBUTION.md)。

## 2. 分叉处是不是平滑制造的连接？

对 source 1681–1740 的 60 层作原图、Gaussian σ=0.6、σ=1.0 与阈值 25/30/35 的九组对照。采用 3D 六邻接，并检查二十六邻接；没有闭运算来补桥。

| 输入 | 阈值 25 | 阈值 30 | 阈值 35 |
|---|---|---|---|
| 未平滑原图 | 连通 | 连通 | 连通 |
| σ=0.6 | 连通 | 连通 | 连通 |
| σ=1.0 | 不连通 | 连通 | 连通 |

未平滑输入已经存在连接，说明连接并非完全由 Gaussian 生成。不过，低阈值下连接经一次体素腐蚀即断；较高阈值下承受的腐蚀次数较多。腐蚀是脆弱性压力测试，**不是根管直径测量**；九组也不是九个独立标本，不能换算成解剖概率。

完整数值与图：`output/branch-denoising/report.json`、`section1698-comparison.png`。此前阈值 40 的明显过分割继续排除，不因其“连通效果好”而采用。

## 3. 根尖方向追踪与一次有价值的失败

首次追踪使用两条相互独立的目标和质心匹配，两者在 source 2430 左右同时丢失。原图检查发现两个暗区之间出现细长连接；共同连通域的质心跳移，使独立目标假设失效。首次失败的 CSV 和报告保留在 `output/root-tracking-first-pass/`。

修订后的算法允许同层两个局部锚点落在共同连通域内；随后可以再次分开。它不预设两根圆管，也不填补缺层。A/B 仅是追踪标签，经过共同区域之后的身份对应仍需审查。

| 阈值 | A 最后封闭层 → 外连候选起始层 | B 最后封闭层 → 外连候选起始层 | 共同连通域层数 |
|---|---|---|---|
| 25 | 2746 → 2747 | 2827 → 2828 | 61 |
| 30 | 2746 → 2747 | 2827 → 2828 | 103 |
| 35 | 2745 → 2746 | 2827 → 2828 | 110 |

三组在各自最后封闭层之前都没有缺失、重新捕获或相邻候选掩膜无重叠的情况。共同区域的首末层范围不代表其中每一层都连通；逐层状态见 `output/root-tracking/profiles.csv`。

“外连候选”指局部低灰度区域通到计算裁剪边缘、附近仍有组织，且连续三层满足规则。**这个筛查规则不是根尖孔的医学定义**，不能用它直接数孔或测工作长度。

图与逐层记录：`output/shared-region-audit/raw-shared-comparison.png`、`report.json`。

## 5. 候选末端的原始灰度路径

在 A、B 最后封闭层前十层选择候选掩膜内部的深部种子，各取局部三维原图；测试原图/σ=0.6 与阈值 20/25/30/35。禁止向种子层以上回走，使用六邻接路径到侧方或根尖方向的 ROI 边界。

- A：原图阈值 25/30/35 均能通达；阈值 20 时种子灰度等于 20，不满足严格 `<20`，该组种子无效，不能说“根管不通”。平滑后的四组均能通达。
- B：八组均能通达。
- 原图阈值 30 下分别保存了 56、45 步的六邻接路径，检查每一步仅跨一个体素且全程符合灰度条件。**这些步数不是临床工作长度**。
- 已逐图查看末端前后的原始切片。可见暗腔逐步向表面开放，但 ROI 边缘不是解剖表面，路径不是根尖孔边界；A/B 路径也不能证明两个彼此独立的正常根尖孔。

可复核文件：`output/root-exits/A-endpoint-sections.png`、`B-endpoint-sections.png`、`A-raw-path.csv`、`B-raw-path.csv`、`report.json`。图中橙线经显示膨胀方便观看，不代表孔径。

## 6. 离线交付与工程验证

`output/root-study/` 提供：

- `raw-canal-roi.nrrd`：1293 层原始灰度的局部裁剪，保留与标签一致的坐标。
- `candidate-lumen.nrrd`：名义阈值 30 的候选腔隙二值标签。
- `candidate-root-system.ply`：标签等值面，未做美化平滑或缺损补管。
- `candidate-labels.npz`、`manifest.json`：标签、源坐标、体素间距、网格与数据校验信息。
- `three-dimensional-candidate.png`：三方向静态预览。

NRRD 的压缩数据已解压回读并逐字节哈希比对；网格检查封闭性和绕向。**网格封闭包含算法在裁剪处和候选末端生成的人工封帽，不代表真实根尖封闭**。没有在医学查看器中进行交互验收，不把格式校验说成软件兼容性全覆盖。

独立导出核验还抽查了九个源层（含数据交界、共同腔隙和末端），确认 NRRD 灰度与源 PNG 裁剪逐像素一致、标签与 NPZ 一致、网格包围盒与源标签物理坐标一致。最终体数据为 1293×310×181，候选体素构成一个六邻接连通域；曲面有 831842 个三角面。连通域数量不是根管数量。核验记录为 `output/root-study/validation.json`。

前段使用 3D Gaussian，后段追踪使用逐层 2D Gaussian；交界没有插值或补缝，重叠检查另记于 manifest。这是阶段性拼接方法，正式研究定量前应统一处理并复核交界。

主项目 `npm run check`、`npm run validate`、`npm run build` 本轮通过。它们只证明工程检查通过，不验证微观解剖。

## 7. 当前能下的结论与下一步

**已验证的技术能力：**可以从公开微 CT 原始图像中连续追踪非圆柱形腔隙，保留局部共同腔隙，并导出与原始切片配对、可回溯的三维候选结果。参数敏感性和追踪失败都可记录，而非通过手工补管隐藏。

**未验证的医学结论：**还没有完整牙冠髓室、正常标本状态、所有微小侧支、根尖孔边界的人工真值，也没有跨标本验证。不能发布完整 Vertucci 分型，不能由这个样本推断常见变异频率，更不能用单个样本直接替换全部牙位。

接下来应在本标本补齐冠方连续数据，建立同一标本牙体外表面与内部腔隙配对；对共同区域及末端作三个正交方向的人工参考标注与误差分析。随后再用独立、许可明确的不同牙型标本复现。这些门槛通过后，才适合制作“默认常见型 + 可替换变异”的正式模型库。
